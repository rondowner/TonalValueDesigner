Measurement Tips and Limitations
  • TonalValueDesigner measures the appearance in a photograph, not an intrinsic paint property.
  • This estimate comes from a photograph. Exposure, white balance, glare, shadows, and room lighting affect the result.
  • To sample the value of mixed paint while painting, the following process is recommended:
    • For comparison, photograph samples in the same frame, lighting, and orientation.
    • Do not sample piles of paint on your palette; these can read differently from paint applied to your canvas.
    • Paint a swatch on or next to your canvas on the easel, in the same lighting and orientation as the canvas.
    • Avoid visible glare.
    • Sample representative flat areas—not highlights or texture shadows.
  • Thin or transparent paint can be influenced by the underlying ground.

Tonal Value Designer

by Ron Downer

Tonal Value Designer is a tool that streamlines the execution of value studies and design decisions based on those value studies leading to a “value plan” for a particular painting. Further, it can be used to validate the resulting artwork conforms to that value plan. To do this it supports the following work process:

  1. Select a reference image. Select an image on your local device.
  2. Create a preliminary value map. This creates a black and white representation of your image - reduces to a number of discrete values. The number of values is up to you.
  3. Mass Values.

    In order to reduce the complexity of a given image, it is important to simplify the values represented in the value map. One way is to mass values. This means to reduce the value “noise” in a given area of the image by making everything in a designated area a single value. In this way, a large area of value 6, for example, that has little flecks of other values can be simplified to ONLY have value 6 in that value mass. Also, nearby features of the same or similar value can be “massed” into a larger value shape.

    Values can be massed in a number of ways, like by drawing a free-form shape or by using a digital “paintbrush” to paint over unwanted complexity.

  4. Conduct what-if studies.

    The power of value studies is the ability to OVERRIDE the values as represented in the reference image to make the image and resulting painting more pleasing, more readable, or more dramatic. AND the reason an artists creates several value studies is to determine which value combinations best serve his/her artistic goals. To do this, an artist must be able to change the values as initially captured in the value map. For example, the overall composition may be more pleasing if the sky is a darker value - or a lighter value. They same with other key elements or value masses in the initially generated value map. Various iterations of value studies can be saved locally, to be compared to one another outside of the tool. One will be selected as the go-forward value design or value map.

  5. Lastly, validate the values you are painting, align with the values in your value map.

    to do this, mix your desired color and paint a small swatch or sample on your canvas / paper. Make sure the sample is in the same lighting and orientation (on your easel, or on your table) as your painting. With this feedback you can then alter the mixed color, if needed.
